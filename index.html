Legtöbb gyümölcs – Keresés, rendezés

Feladatleírás
Egymás mellett ládák állnak, mindegyikben alma (A) vagy körte (K) van. Minden ládában pontosan az egyik fajta gyümölcs, és összesen ugyanannyi almás láda van, mint körtés. Egy kamion balról jobbra végigmegy a ládasor mellett. Minden ládánál eldönthetjük, hogy felrakjuk, vagy otthagyjuk. Először csak almás ládákat tehetünk fel, utána csak körtéseket, és a felrakott almák és körték darabszáma legyen ugyanannyi.

Kérdés: maximum hány ládát tudunk így felpakolni a kamionra?
Bemenet
Az első sorban N, a ládák száma (páros, és legfeljebb 100 000).
A második sorban egy N hosszú szöveg, csak 'A' és 'K' karakterekkel: a ládák tartalma balról jobbra.
Kimenet
Egyetlen szám: a maximálisan felrakható ládák száma.
Példa
Bemenet: 
8
AAKAAKKK
Kimenet: 
6
Lehetséges megoldás: az első három A, majd az utolsó három K láda (AAA KKK).
Megoldási mód (Python)
import sys

def main():
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()

    # prefixA[i] = az első i ládában hány A van
    prefixA = [0] * (n + 1)
    for i, ch in enumerate(s, start=1):
        prefixA[i] = prefixA[i - 1] + (1 if ch == "A" else 0)

    # suffixK[i] = az i..n ládákban hány K van
    suffixK = [0] * (n + 2)
    for i in range(n, 0, -1):
        suffixK[i] = suffixK[i + 1] + (1 if s[i - 1] == "K" else 0)

    best = 0
    # i után vágjuk el a sort: 1..i almák, i+1..n körték
    for i in range(1, n):
        if prefixA[i] == suffixK[i + 1]:
            best = max(best, 2 * prefixA[i])

    print(best)

if __name__ == "__main__":
    main()

Magyarázat:
Úgy gondolkodunk, hogy valahol „elvágjuk” a sort: balra almákat veszünk fel, jobbra körtéket. Ehhez végigszámoljuk, hogy az első i ládában hány A van (prefixA), és hátulról, hogy az i+1..N tartományban hány K van (suffixK).

Ott jó az elvágás, ahol a bal oldali A-k száma megegyezik a jobb oldali K-k számával. Ha X ilyen, akkor 2·X ládát tudunk felrakni (X A + X K). Végigpróbáljuk az összes i-t, és megjegyezzük a legnagyobb értéket.

Mivel csak egyszer megyünk végig a soron előre és egyszer hátra, az algoritmus lineáris idejű: nagyjából O(N).

Hanoi tornyai variáns – Rekurzió

Feladatleírás
Az OKTV-feladat a klasszikus Hanoi tornyai játék egy változata. A kiinduló és a cél játékállásban is tetszőlegesen elhelyezkedhetnek a korongok a három tornyon, amíg mindenhol igaz, hogy egy korong csak nála nagyobb korongon áll.

Egy lépésben egy korongot vehetünk le valamelyik torony tetejéről, és áttehetjük egy másik torony tetejére, ha ott a tetején lévő korong nagyobb nála (vagy üres a torony).

A feladat: olyan lépéssorozatot kell találni, amely a kiinduló állást átalakítja a célállássá. A bemenetben a kezdő és a célállást is a három torony tartalma írja le.
Bemenet
Az OKTV verzióban 6 sor van: 3 sor a kezdő állapot tornyai (csökkenő sorrendben a korongméretek), majd 3 sor a célállapot tornyai, mindegyik sort 0 zárja le.

Itt most a rekurzió bemutatásához az egyszerűbb alapváltozatot fogjuk kódban mutatni: csak azt kérdezzük be, hány korong van, és abból indulunk ki, hogy az összes korong az 1. tornyon van, a cél, hogy a 3. tornyra kerüljenek.
Kimenet
A lépések száma, majd soronként egy-egy lépés: honnan hova mozgatjuk a korongot (forrás torony, cél torony).
Példa
Bemenet: 
3
Kimenet (lehetséges): 
7
1 3
1 2
3 2
1 3
2 1
2 3
1 3
Ez 3 korong átpakolása az 1. toronyról a 3.-ra, a szokásos minimális lépésszámmal.
Megoldási mód (Python – alap Hanoi)
def hanoi(n, src, aux, dest, moves):
    """n korong átvitele src-ről dest-re aux segítségével."""
    if n == 0:
        return
    # 1) vigyük a n-1 kisebb korongot a segédtoronyra
    hanoi(n - 1, src, dest, aux, moves)
    # 2) vigyük a legnagyobbat a célra
    moves.append((src, dest))
    # 3) a kisebbeket tegyük rá a célon lévő legnagyobbra
    hanoi(n - 1, aux, src, dest, moves)

def main():
    n = int(input("Korongok száma: "))
    moves = []
    hanoi(n, 1, 2, 3, moves)

    print(len(moves))
    for a, b in moves:
        print(a, b)

if __name__ == "__main__":
    main()

Magyarázat:
Itt a klasszikus Hanoi feladat rekurzív megoldását mutatom meg, mert ezen látszik szépen, hogyan működik a rekurzió.

Ha n korongot szeretnénk az 1. toronyról a 3.-ra vinni:

  • Először az n-1 kisebb korongot visszük át a segédtoronyra (2.).
  • Utána átvisszük a legnagyobb korongot közvetlenül a célra (3.).
  • Végül az n-1 kisebb korongot átpakoljuk a segédtoronyról a célra, immár a legnagyobb korong tetejére.
Minden lépésnél ugyanaz a gondolat: „oldjuk meg a feladatot kevesebb korongra”. Ez a tiszta rekurziós minta. A versenyfeladatban a kezdő és célállás bonyolultabb, de az ötlet hasonló: a nagyobb korongok pozíciója határozza meg, mely kisebb korongokat kell előbb elmozgatni.

Fesztivál – Dinamikus programozás

Feladatleírás
Egy városban N fesztiválra jelentkeztek. Minden fesztiválról tudjuk: mikor kezdődik, mikor ér véget, és mennyi bevételt hozna. Egy időben csak egy fesztivál lehet, tehát a kiválasztott fesztiválok időintervallumai nem fedhetik egymást.

Feladat: válasszunk ki néhány fesztivált úgy, hogy ne ütközzenek, és a bevételek összege maximális legyen. A kimenetben a legnagyobb bevételt, valamint egy ilyen fesztiválhalmazt kell megadni.
Bemenet
Az első sorban N (1 ≤ N ≤ 100 000), a fesztiválok száma.
A következő N sor mindegyike: kezdőnap, utolsó nap, bevétel.
Kimenet
Az első sor: az elérhető legnagyobb bevétel.
A második sor: először a kiválasztott fesztiválok száma, aztán a fesztiválok indexei (1-től N-ig), tetszőleges sorrendben.
Példa
Bemenet: 
4
2 5 100
1 3 60
5 6 50
4 5 30
Kimenet (egy lehetséges): 
110
2 3 2
Itt a 2. és 3. fesztivál (1–3 és 5–6 nap között) együtt adja a 110 bevételt, és nem ütköznek.
Megoldási mód (Python – DP intervallumokra)
import sys
import bisect

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))

    festivals = []
    for idx in range(1, n + 1):
        start = int(next(it))
        end = int(next(it))
        profit = int(next(it))
        festivals.append((end, start, profit, idx))

    # rendezzük befejezési idő szerint
    festivals.sort()
    ends = [f[0] for f in festivals]

    # p[i] = utolsó olyan fesztivál indexe, ami nem ütközik az i. fesztivállal
    p = [0] * n
    for i in range(n):
        end_i, start_i, _, _ = festivals[i]
        # olyan fesztivált keresünk, ami legkésőbb start_i - 1-nél ér véget
        j = bisect.bisect_right(ends, start_i - 1, 0, i) - 1
        p[i] = j

    # dp[i] = legnagyobb bevétel az első i fesztivál (0..i-1) figyelembevételével
    dp = [0] * (n + 1)
    take = [False] * n

    for i in range(1, n + 1):
        end_i, start_i, profit_i, _ = festivals[i - 1]
        # 1) nem vesszük fel az i. fesztivált
        option1 = dp[i - 1]
        # 2) felvesszük: profit + dp[p[i-1] + 1]
        option2 = profit_i + dp[p[i - 1] + 1]

        if option2 > option1:
            dp[i] = option2
            take[i - 1] = True
        else:
            dp[i] = option1

    # visszafejtés: mely fesztiválokat vettük fel
    chosen = []
    i = n
    while i > 0:
        if take[i - 1]:
            chosen.append(festivals[i - 1][3])  # eredeti index
            i = p[i - 1] + 1
        else:
            i -= 1

    chosen.reverse()
    print(dp[n])
    if chosen:
        print(len(chosen), *chosen)
    else:
        print(0)

if __name__ == "__main__":
    main()

Magyarázat:
Itt klasszikus dinamikus programozást használunk, „időintervallumokra”.

1. lépés – rendezés: a fesztiválokat a befejezési napjuk szerint rendezzük. Ez azért jó, mert ha tudjuk, hogy az i. fesztivál meddig tart, elég visszafelé keresni az utolsó olyan fesztivált, ami ennél előbb fejeződik be – vele nem ütközik.

2. lépés – p[i] tömb: minden i-hez eltároljuk, hogy mi az utolsó nem ütköző fesztivál indexe. Ehhez bináris keresést használunk a rendezett befejezési idők között.

3. lépés – dp[i]: legyen dp[i] a legnagyobb bevétel, amit az első i rendezett fesztivál figyelembevételével el tudunk érni. Két választásunk van az i. fesztiválnál:

  • nem vesszük fel → dp[i] = dp[i-1]
  • felvesszük → a bevétele + dp[p[i-1] + 1]
A kettő közül a nagyobb kerül dp[i]-be.

4. lépés – visszafejtés: a take tömbből visszafelé indulva megnézzük, mely fesztiváloknál választottuk a „felvesszük” ágat, így kapjuk a konkrét fesztiválhalmazt.

Sípálya – Fa- és gráfalgoritmus

Feladatleírás
Egy hegyoldalon sípálya van, elágazási pontokkal. A startponttól (1-es csúcs) a célpontig (N-es csúcs) többféle útvonalon lehet lecsúszni. Az elágazási pontok között egyirányú pályaszakaszok vannak, mindig magasabbról alacsonyabb pontra.

Minden verseny előtt ellenőrök mennek le a pályán. Minden ellenőr a starttól indul és egy teljes útvonalon végigmegy a célig. A cél: úgy választani az útvonalakat, hogy minden pályaszakaszon áthaladjon legalább egy ellenőr, és közben az ellenőrök száma a lehető legkisebb legyen.
Bemenet
Az első sorban N, az elágazási pontok száma (1 ≤ N ≤ 20 000). A pontokat 1..N sorszámmal jelölik, 1 a start, N a cél.

A következő N-1 sor: az i-edik sor az i-edik pontból induló pályaszakaszokat írja le. Először egy szám: hány kimenő él van onnan; utána a célpont(ok) sorszámai.
Kimenet
Egy egész szám: a szükséges legkisebb ellenőrszám.
Példa
Bemenet: 
10
3 2 3 4
2 5 6
1 6
3 6 7 8
1 10
1 10
2 10 9
1 9
1 10
Kimenet: 
7
Itt 7 különböző útvonal elég ahhoz, hogy minden pályaszakaszon legalább egy ellenőr átmenjen.
Megoldási mód (Python – oktató jellegű, kis N-re)
from collections import defaultdict

def dfs_paths(graph, node, target, path, paths):
    """Összes útvonal gyűjtése 1-től N-ig (kis gráfra)."""
    path.append(node)
    if node == target:
        paths.append(path.copy())
    else:
        for nxt in graph[node]:
            dfs_paths(graph, nxt, target, path, paths)
    path.pop()

def main():
    n = int(input().strip())
    graph = defaultdict(list)

    for i in range(1, n):
        parts = list(map(int, input().split()))
        k = parts[0]
        for v in parts[1:1 + k]:
            graph[i].append(v)

    # 1) összes útvonal 1-től N-ig (ez csak kis N esetén használható)
    all_paths = []
    dfs_paths(graph, 1, n, [], all_paths)

    # minden él azonosítása (u,v)
    edges = set()
    for u in graph:
        for v in graph[u]:
            edges.add((u, v))

    # 2) minden útvonalhoz: mely éleket érinti
    path_edges = []
    for p in all_paths:
        es = set()
        for i in range(len(p) - 1):
            es.add((p[i], p[i + 1]))
        path_edges.append(es)

    # 3) nagyon egyszerű mohó: mindig azt az útvonalat választjuk,
    #    ami a legtöbb még lefedetlen élt tartalmazza
    uncovered = set(edges)
    used_paths = 0

    while uncovered:
        best_idx = None
        best_cover = 0
        for i, es in enumerate(path_edges):
            cover = len(uncovered & es)
            if cover > best_cover:
                best_cover = cover
                best_idx = i
        if best_idx is None:
            break  # elvileg nem fordulhat elő jól megadott pályánál
        uncovered -= path_edges[best_idx]
        used_paths += 1

    print(used_paths)

if __name__ == "__main__":
    main()

Magyarázat:
Ez a kód nemkis példákon.

Lépések:

  1. Gráf beolvasása – minden csúcsból eltároljuk, melyekbe vezetnek élek.
  2. Összes útvonal – egy rekurzív DFS-sel összegyűjtjük az összes lehetséges utat 1-től N-ig.
  3. Élek gyűjtése – összeszedjük az összes (u,v) élpárt.
  4. Mohó lefedés – amíg van lefedetlen él, mindig azt az útvonalat választjuk, amelyik a legtöbb ilyen élt érinti. Ezzel „lefedezzük” az éleket útvonalakkal.
Így kapunk egy közelítést a minimális ellenőrszámra. Nagy N esetén ez nem futna elég gyorsan, de tanításra jól megmutatja, hogyan gondolunk a pályára, mint gráfra, és mit jelent az, hogy „útvonalakkal lefedjük az éleket”.
