Ötlet, rövid magyarázat

A sorban almás (A) és körtés (K) ládák vannak. Valahol kettéválasztjuk a sort: bal oldalon almákat veszünk fel, jobb oldalon körtéket. A jó hely ott van, ahol a bal oldalon lévő almák száma megegyezik a jobb oldalon lévő körték számával.

Megoldási mód

read N read S[1..N] // 'A' vagy 'K' prefixA[0] = 0 for i = 1..N: prefixA[i] = prefixA[i-1] + (S[i] == 'A' ? 1 : 0) suffixK[N+1] = 0 for i = N downTo 1: suffixK[i] = suffixK[i+1] + (S[i] == 'K' ? 1 : 0) best = 0 for i = 1..N-1: if prefixA[i] == suffixK[i+1]: best = max(best, 2 * prefixA[i]) print best

Itt jól látszik, hogy egyszer végigmegyünk a soron előre, egyszer hátra, majd egyszer még végig ellenőrzünk. Ezért az időigény nagyjából O(N).

Ötlet, rövid magyarázat

A fesztiválokat időszakoknak tekintjük. Csak olyan fesztiválokat választhatunk, amelyek nem fedik egymást. Először rendezzük őket a befejezési nap szerint, ezután dinamikus programozással döntjük el, hogy érdemes-e felvenni az i. fesztivált vagy nem, hogy a bevétel maximalizálódjon.

Megoldási mód

// dp[i] = legnagyobb bevétel az első i fesztivál figyelembevételével // p[i] = utolsó fesztivál indexe i előtt, ami nem ütközik i-vel dp[0] = 0 for i = 1..N: dp[i] = max( dp[i-1], // i. fesztivált kihagyjuk profit[i] + dp[p[i]] // i. fesztivált kiválasztjuk ) print dp[N]

A rendezés és az ütközések keresése miatt a megoldás dinamikus programozás és rendezés kombinációja. A futásidő kb. O(N log N).
